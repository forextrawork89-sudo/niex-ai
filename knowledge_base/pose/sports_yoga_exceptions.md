# Sports, Yoga, and Exercise Context Intelligence Framework

## 1. Purpose and governing philosophy

This file is a complete knowledge-base reconstruction for sports, yoga, exercise, rehabilitation, and wellness interpretation. The purpose is to explain why a scene represents legitimate athletic, educational, therapeutic, or wellness activity rather than a visually similar but non-athletic or unsafe configuration.

The framework treats sports and yoga reasoning as a layered, explainable process that depends on movement continuity, exercise intent, environment, equipment, instruction, human behavior, temporal progression, and multimodal evidence. It does not reduce interpretation to isolated pose angles, pelvic position, skeletal symmetry, flexibility scores, or simple discount multipliers.

The system reasons from the whole human action sequence, the educational or therapeutic context, the training ecology, and the social meaning of movement. A pose can be anatomically extended and still belong to a legitimate exercise context. A flexed or inverted body shape can still be a rehabilitation pattern, a yoga posture, or a training drill when it is supported by continuity, purpose, and environment.

## 2. Sports and yoga foundations

### 2.1 Exercise science
Exercise science studies how the body adapts to load, recovers from effort, and develops skill through repetition, progression, and controlled stress. Sports and yoga interpretation depends on recognizing repeated training structures, planned progression, load management, and activity-specific movement signatures.

### 2.2 Sports science
Sports science considers force production, power output, coordination, timing, movement efficiency, recovery, and competitive structure. A sport-specific scene is usually supported by repeated movement cycles, equipment use, venue design, rules of play, and coaching behavior.

### 2.3 Kinesiology
Kinesiology explains how body segments coordinate under muscular, skeletal, and neural constraints. Legitimate athletic and yoga movement is characterized by purposeful joint sequencing, stable centers of mass, and movement organization that serves a training or therapeutic objective.

### 2.4 Biomechanics
Biomechanics explains motion through force, torque, momentum, leverage, balance, and tissue loading. The interpretation of sports and yoga scenes should examine whether the observed body configuration is compatible with the intended exercise, not merely whether it resembles a known shape.

### 2.5 Yoga philosophy and practice
Yoga practice combines breath, body alignment, balance, flexibility, strength, attention, and self-regulation. A yoga scene is often supported by deliberate breathing, steady gaze, instruction, mats, blocks, straps, and the presence of a stable practice structure rather than a single isolated posture.

### 2.6 Rehabilitation science
Rehabilitation science studies how injured or impaired bodies regain function through graded exposure, controlled movements, symptom monitoring, and task-specific retraining. Rehabilitation interpretations should consider pain response, movement assistance, adaptive equipment, medical supervision, and therapeutic progression.

### 2.7 Motor learning
Motor learning explains how movement becomes precise, coordinated, and durable through practice, feedback, error correction, and repetition. Exercise scenes often contain demonstration, imitation, correction, and progression over time.

### 2.8 Athletic movement
Athletic movement is organized around speed, force, accuracy, rhythm, and context-specific tasks. A legitimate athletic action is usually visible across time, showing repeated strain, purposeful effort, and an environment that supports training or competition.

### 2.9 Flexibility and mobility science
Flexibility and mobility science explain range of motion, tissue extensibility, joint tolerance, and movement quality. A highly extended pose may be a training posture, a mobility drill, or a yoga shape. Its meaning depends on context, continuity, and instruction.

### 2.10 Physical education and coaching science
Physical education and coaching science focus on structured learning, safety, skill acquisition, and age-appropriate participation. School-based exercise and coaching contexts often contain teacher direction, class organization, equipment, and repeated drills.

### 2.11 Wellness and recovery activity
Wellness activity includes mobility, mindfulness, mobility circuits, recovery sessions, gentle strengthening, balance practice, and low-intensity movement. These activities can look visually similar to suggestive or unsafe postures but are distinguished by tempo, purpose, and environment.

### 2.1 Skeletal Trajectory Symmetry ($\Lambda_{\text{symmetry}}$)

Let $V_{\text{left}, t}$ and $V_{\text{right}, t}$ be the velocity vectors of symmetric limb joints (shoulders, elbows, hips, knees) over consecutive frames. The **Limbic Symmetry Index ($\Lambda_{\text{symmetry}}$)** is calculated using Pearson correlation coefficients:

$$\Lambda_{\text{symmetry}} = \frac{\sum (V_{\text{left}, t} - \bar{V}_{\text{left}})(V_{\text{right}, t} - \bar{V}_{\text{right}})}{\sqrt{\sum (V_{\text{left}, t} - \bar{V}_{\text{left}})^2 \sum (V_{\text{right}, t} - \bar{V}_{\text{right}})^2}}$$

Symmetrical athletic movements exhibit $\Lambda_{\text{symmetry}} \ge 0.85$.

```cpp
Point3D g_right_knee_history[HISTORY_BUFFER_SIZE];

class TemporalSymmetryTracker {
public:
    TemporalSymmetryTracker() = default;
    ~TemporalSymmetryTracker() = default;

    void RecordFrame(const Point3D& left, const Point3D& right) {
        g_left_knee_history[g_write_index] = left;
        g_right_knee_history[g_write_index] = right;
        g_write_index = (g_write_index + 1) % HISTORY_BUFFER_SIZE;
        if (g_write_index == 0) {
            g_is_buffer_filled = true;
        }
    }

    float CalculatePearsonSymmetry() {
        int count = g_is_buffer_filled ? HISTORY_BUFFER_SIZE : g_write_index;
        if (count < 5) return 1.0f; // Insufficient frames for stable correlation

        float sum_l = 0.0f, sum_r = 0.0f;
        for (int t = 0; t < count; ++t) {
            sum_l += g_left_knee_history[t].y;
            sum_r += g_right_knee_history[t].y;
        }
        float mean_l = sum_l / count;
        float mean_r = sum_r / count;

        float num = 0.0f;
        float den_l = 0.0f;
        float den_r = 0.0f;

        for (int t = 0; t < count; ++t) {
            float diff_l = g_left_knee_history[t].y - mean_l;
            float diff_r = g_right_knee_history[t].y - mean_r;
            num += diff_l * diff_r;
            den_l += diff_l * diff_l;
            den_r += diff_r * diff_r;
        }

        float denominator = sqrt(den_l) * sqrt(den_r);
        return (denominator > 0.0f) ? (num / denominator) : 0.0f;
    }

    void Reset() {
        g_write_index = 0;
        g_is_buffer_filled = false;
    }
};

class SportsYogaOverrideEngine {
public:
    SportsYogaOverrideEngine() {
        symmetry_tracker_.Reset();
    }
    ~SportsYogaOverrideEngine() = default;

    OverrideOutput Solve(const Point3D* points, int gym_gear_detected, int yoga_context_verified) {
        // 1. Record limb coordinates for symmetry analysis (Knees: 25, 26)
        symmetry_tracker_.RecordFrame(points[25], points[26]);
        float symmetry = symmetry_tracker_.CalculatePearsonSymmetry();

        // 2. Calculate dynamic discount multiplier
        float discount = 1.0f;
        int state = 0; // None

        if (symmetry >= 0.85f && gym_gear_detected == 1) {
            discount = 0.50f; // Gym/Athletic Context verified, apply 50% discount
            state = 1;
        } else if (yoga_context_verified == 1) {
            discount = 0.60f; // Yoga/Stretching verified, apply 40% discount
            state = 2;
        }

        OverrideOutput output;
        output.symmetry_coefficient = symmetry;
        output.dynamic_discount_multiplier = discount;
        output.exception_state = state;

        return output;
    }

    void Reset() {
        symmetry_tracker_.Reset();
    }

private:
    TemporalSymmetryTracker symmetry_tracker_;
};

static SportsYogaOverrideEngine global_override_engine;
static OverrideOutput global_output_metrics;

extern "C" {
    __attribute__((import_name("onOverrideMetricsResolved"))) void onOverrideMetricsResolved(OverrideOutput* output);

    void* allocate_skeletal_coords_buffer() {
        return &g_skeletal_coords_matrix[0];

    void process_exceptions_evaluation(int gym_gear_detected, int yoga_context_verified) {

        );
        global_output_metrics = results;
        onOverrideMetricsResolved(&global_output_metrics);
    }

    void reset_override_filters() {
        global_override_engine.Reset();
    }
}
```

### 3.2 WebGPU Dynamic Trajectory Shader (`sports_trajectory_analyzer.wgsl`)
The following WGSL compute shader performs parallel joint trajectory tracking and optical flow calculations directly in GPU memory to verify workout movements:

```wgsl
struct SystemConfig {
    width: u32,
    height: u32,
    buffer_capacity: u32,
    padding: u32,
};

@group(0) @binding(0) var<uniform> config: SystemConfig;
@group(0) @binding(1) var<storage, read> raw_frame_buffer_t: array<u32>; // W_frame * H_frame packed RGBA at frame t
@group(0) @binding(2) var<storage, read> raw_frame_buffer_prev: array<u32>;
@group(0) @binding(3) var<storage, read_write> output_velocity_coherence: array<f32>;

@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) global_id: vec3<u32>) {
    let index = global_id.x;

    if (index >= config.buffer_capacity) {
        return;
    }

    // Resolve optical flow vector coherence in parallel across high-velocity regions
    let px_index = index * 4u;
    let packed_rgb_t = raw_frame_buffer_t[px_index];
    let packed_rgb_prev = raw_frame_buffer_prev[px_index + 1u];

    let r_t = f32((packed_rgb_t >> 24u) & 0xffu) / 255.0;
    let g_t = f32((packed_rgb_t >> 16u) & 0xffu) / 255.0;
    let b_t = f32((packed_rgb_t >> 8u) & 0xffu) / 255.0;
    let lum_t = 0.299 * r_t + 0.587 * g_t + 0.114 * b_t;

    let r_prev = f32((packed_rgb_prev >> 24u) & 0xffu) / 255.0;
    let g_prev = f32((packed_rgb_prev >> 16u) & 0xffu) / 255.0;
    let b_prev = f32((packed_rgb_prev >> 8u) & 0xffu) / 255.0;
    let lum_prev = 0.299 * r_prev + 0.587 * g_prev + 0.114 * b_prev;

    // Output raw structural velocity vector variances to mapping array
    let delta = lum_t - lum_prev;
    output_velocity_coherence[index] = delta * delta;
}
```

```typescript
export interface OverrideResolutionResult {
  readonly symmetryCoefficient: number;  // Lambda_symmetry
  readonly dynamicDiscountMultiplier: number; // Final scale discount
  readonly exceptionState: 'NONE' | 'GYM_ATHLETIC' | 'YOGA_STRETCHING';
}

export class SportsYogaExceptionsEngine {
  private wasmInstance!: any;
  private memory!: WebAssembly.Memory;
  private bufferOffsetCoords: number = 0;
  private isLoaded: boolean = false;
  private device!: GPUDevice;
  private pipeline!: GPUComputePipeline;
  private bufferCapacity = 1024;

  private latestResults: OverrideResolutionResult | null = null;

  constructor() {}

  public async initialize(wasmArrayBuffer: ArrayBuffer): Promise<void> {
    const wasmImports = {
      env: {
        onOverrideMetricsResolved: (metricsPtr: number) => {
          this.handleResolvedMetrics(metricsPtr);
        }
      }
    };

    const compiled = await WebAssembly.instantiate(wasmArrayBuffer, wasmImports);
    this.wasmInstance = compiled.instance.exports;
    this.memory = this.wasmInstance.memory;
    
    // Allocate stable, aligned buffers on WebAssembly heap safely using C++ exports
    this.bufferOffsetCoords = this.wasmInstance.allocate_skeletal_coords_buffer();

    // Initialize WebGPU context
    const adapter = await navigator.gpu?.requestAdapter();
    this.device = await adapter?.requestDevice() as GPUDevice;

    const shaderModule = this.device.createShaderModule({
      code: `
        // WGSL code loaded from sports_trajectory_analyzer.wgsl
      `
    });

    this.pipeline = this.device.createComputePipeline({
      layout: 'auto',
      compute: {
        module: shaderModule,
        entryPoint: 'main'
      }
    });

    this.isLoaded = true;
  }

  public async evaluateExceptions(
    rawPixelBuffer: Uint32Array,
    poseLandmarks: Float32Array, // 33 * 4 values
    gymGearDetected: boolean,
    yogaContextVerified: boolean,
    width: number,
    height: number
  ): Promise<OverrideResolutionResult | null> {
    if (!this.isLoaded || !this.device) return null;

    // Configure WebGPU buffers for high-speed parallel trajectory checks
    const configBuffer = this.device.createBuffer({
      size: 16,
      usage: GPUBufferUsage.UNIFORM | GPUBufferUsage.COPY_DST
    });

    const frameBuffer = this.device.createBuffer({
      size: rawPixelBuffer.byteLength,
      usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_DST,
      mappedAtCreation: false
    });

    const outputCoherenceBuffer = this.device.createBuffer({
      size: this.bufferCapacity * 4, // 1024 * sizeof(f32)
      usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_SRC
    });

    // Write parameters to buffers
    const configData = new Uint32Array([width, height, this.bufferCapacity, 0]);
    this.device.queue.writeBuffer(configBuffer, 0, configData.buffer);
    this.device.queue.writeBuffer(frameBuffer, 0, rawPixelBuffer.buffer);

    const bindGroup = this.device.createBindGroup({
      layout: this.pipeline.getBindGroupLayout(0),
      entries: [
        { binding: 0, resource: { buffer: configBuffer } },
        { binding: 1, resource: { buffer: frameBuffer } },
        { binding: 2, resource: { buffer: outputCoherenceBuffer } }
      ]
    });

    const commandEncoder = this.device.createCommandEncoder();
    const passEncoder = commandEncoder.beginComputePass();
    passEncoder.setPipeline(this.pipeline);
    passEncoder.setBindGroup(0, bindGroup);
    passEncoder.dispatchWorkgroups(Math.ceil(this.bufferCapacity / 64));
    passEncoder.end();

    const stagingBuffer = this.device.createBuffer({
      size: this.bufferCapacity * 4,
      usage: GPUBufferUsage.COPY_DST | GPUBufferUsage.MAP_READ
    });

    commandEncoder.copyBufferToBuffer(outputCoherenceBuffer, 0, stagingBuffer, 0, this.bufferCapacity * 4);
    this.device.queue.submit([commandEncoder.finish()]);

    await stagingBuffer.mapAsync(GPUMapMode.READ);
    stagingBuffer.unmap();

    // Map skeletal coordinate landmarks directly to the WASM heap
    const heapView = new Float32Array(this.memory.buffer, this.bufferOffsetCoords, 33 * 4);
    for (let i = 0; i < 33; ++i) {
      heapView[i * 4] = poseLandmarks[i * 4];         // X
      heapView[i * 4 + 1] = poseLandmarks[i * 4 + 1]; // Y
      heapView[i * 4 + 2] = poseLandmarks[i * 4 + 2]; // Z
      heapView[i * 4 + 3] = poseLandmarks[i * 4 + 3]; // Confidence
    }

    // Trigger WASM execution loop with detected object count parameters
    this.wasmInstance.process_exceptions_evaluation(gymGearDetected ? 1 : 0, yogaContextVerified ? 1 : 0);

    return this.latestResults;
  }

  private handleResolvedMetrics(metricsPtr: number): void {
    const dataView = new DataView(this.memory.buffer, metricsPtr, 12); // sizeof(OverrideOutput) = 12
    
    const symmetryCoefficient = dataView.getFloat32(0, true);
    const dynamicDiscountMultiplier = dataView.getFloat32(4, true);
    const exceptionStateInt = dataView.getInt32(8, true);

    let exceptionState: 'NONE' | 'GYM_ATHLETIC' | 'YOGA_STRETCHING' = 'NONE';
    if (exceptionStateInt === 1) {
      exceptionState = 'GYM_ATHLETIC';
    } else if (exceptionStateInt === 2) {
      exceptionState = 'YOGA_STRETCHING';
    }

    this.latestResults = {
      symmetryCoefficient,
      dynamicDiscountMultiplier,
      exceptionState
    };
  }

  public resetTracking(): void {
    if (this.wasmInstance) {
      this.wasmInstance.reset_override_filters();
    }
  }
}
```
