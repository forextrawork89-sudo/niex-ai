# Commercial Monetization Context Intelligence Framework
This document is the authoritative research knowledge base for commercial monetization context intelligence across multimodal apparel and digital content reasoning.
It explains how commercial intent is identified, how monetization differs from ordinary content, how sponsorship and creator economy signals emerge, and how contextual reasoning leads to explainable commercial decisions.
This framework is conceptual, not implementation specific. It preserves high-level evidence, ontology, reasoning, confidence, uncertainty, and governance for commercial-context AI.

## 1. Purpose, Scope, and Principles
This framework defines the conceptual foundations for recognizing commercial intent and monetization context in imagery, text, and audio evidence.
It is designed for systems that must distinguish between ordinary social media content, personal activity imagery, and content with monetization or advertising purpose.
It is intentionally broad and multimodal, because commercial intent can be signaled through objects, environment, people, brand signals, behavior, timing, and contextual cues.

## 2. Commercial Ecosystem Foundations
Commercial ecosystems include marketplace listings, sponsored social media posts, affiliate networks, livestream shopping, brand partnerships, and paid promotional campaigns.
Creator economy and digital advertising are tightly linked: creators monetize through subscriptions, sponsorships, product placement, donations, commissions, and exclusive commerce experiences.
Understanding commercial context requires mapping observed signals to economic intent, not merely to the presence of brands or products.

## 8. Uncertainty Architecture
Uncertainty captures unresolved or conflicting evidence and is essential for safe commercial reasoning.
### 8.1 Sponsorship Ambiguity
Definition: Sponsorship Ambiguity identifies a specific category of ambiguous signal in commercial interpretation.
Examples: object presence without explicit promotion, branding in a personal context, creator content that lacks monetization clues, inconsistent environment, changing imagery, and low-quality footage.
Propagation: uncertainty should be carried forward and combined with other uncertainty sources rather than eliminated prematurely.
Resolution: when additional evidence appears, uncertainty can be reduced, but the reasoning system should preserve the prior state for auditability.
Downstream interpretation: the final decision should always include uncertainty alongside confidence.

### 2.1 Joint Commercial Monetization Index ($S_{\text{monetization}}$)

Let $W_{\text{retail\_lex}}$ be the on-device calculated weight of commercial words, $L_{\text{catalog\_layout}}$ be the probability of a structured e-commerce product grid, and $S_{\text{posture\_risk}}$ be the calculated skeletal pose risk score (from [post_risk_scoring.md](../pose/post_risk_scoring.md)).

The **Joint Commercial Monetization Index ($S_{\text{monetization}}$)** is calculated locally as:

$$
S_{\text{monetization}} = \left( W_{\text{retail\_lex}} \cdot 0.45 \right) + \left( L_{\text{catalog\_layout}} \cdot 0.35 \right) + \left( (1.0 - S_{\text{posture\_risk}}) \cdot 0.20 \right) \cdot \Phi_{\text{scale\_norm}}
$$

*   $W_{\text{retail\_lex}}$ is the on-device calculated weight of commercial words.

*   $L_{\text{catalog\_layout}}$ is the probability of a structured e-commerce product grid.

*   $S_{\text{posture\_risk}}$ is the calculated skeletal pose risk score.

*   $\Phi_{\text{scale\_norm}}$ is the scale-invariant dynamic distance normalization factor to prevent false positive sheerness triggers on distant, blurry subjects (derived from [distance_patterns.md](../body_shape/distance_patterns.md)).

### 2.2 Flat Studio Background Segmentation Variance ($\sigma^2_{\text{studio}}$)

E-commerce catalog photography typically utilizes solid-color, flat studio backdrops. The system calculates the chrominance variance of the background region $BG_{\text{mask}}$ to identify professional studio setups:

$$\sigma^2_{\text{studio}} = \frac{1}{N} \sum_{i=0}^{N-1} \|(Cb_i, Cr_i) - (\bar{Cb}, \bar{Cr})\|^2$$

Where $(Cb, Cr)$ represents the chrominance coordinates in YCbCr color space. Professional studio backgrounds exhibit extremely low chroma variance ($\sigma^2_{\text{studio}} < 0.02$).

```cpp
constexpr int MAX_OBJECTS_COUNT = 12;
constexpr int MAX_MASK_SIZE = 2073600; // Expanded 1920 * 1080 max mask resolution (Safe Buffer)

struct Point3D {
    float x;
    float y;
    float z;
    float confidence;

struct BoundingBox {
    float min_x;
    float max_x;
    float min_y;
    float max_y;

struct RetailMetricsOutput {
    float commercial_word_density; // W_retail_lex
    float studio_background_index; // 1.0 - sigma^2_studio
    float catalog_grid_probability; // L_catalog_layout
    float dynamic_retail_multiplier; // Key output: M_retail
    int commercial_flag;           // 0 = None, 1 = Product Listing, 2 = Whitelisted Store Domain

uint8_t g_person_mask_buffer[MAX_MASK_SIZE];
char g_retail_text_buffer[TEXT_BUFFER_SIZE];

class RetailLayoutValidator {
public:
    static float CalculateGridProbability(const BoundingBox* boxes, int count) {
        if (count < 3) return 0.0f;

        // Structured e-commerce products are arranged in highly aligned grids
        int vertical_alignments = 0;
        int horizontal_alignments = 0;

        for (int i = 0; i < count; ++i) {
            for (int j = i + 1; j < count; ++j) {
                // Check vertical alignment (row alignment)
                if (std::abs(boxes[i].min_y - boxes[j].min_y) < 0.05f) {
                    horizontal_alignments++;
                }
                // Check horizontal alignment (column alignment)
                if (std::abs(boxes[i].min_x - boxes[j].min_x) < 0.05f) {
                    vertical_alignments++;
                }
            }
        }

        float total_alignments = static_cast<float>(horizontal_alignments + vertical_alignments);
        return std::clamp(total_alignments / (count * 1.5f), 0.0f, 1.0f);
    }
};

class CommercialIntentSolver {
public:
    CommercialIntentSolver() = default;
    ~CommercialIntentSolver() = default;

    RetailMetricsOutput Solve(const Point3D* points, const BoundingBox* boxes, int obj_count, float word_density, float bg_variance, float distance_meters) {
        // 1. Calculate Grid Probability
        float grid_prob = RetailLayoutValidator::CalculateGridProbability(boxes, obj_count);

        // Apply scale normalization based on physical distance (Anti-Evasion Check)
        if (distance_meters > 8.0f) {
            grid_prob = grid_prob * 1.50f; // Scale sensitivity under far-field limits
            grid_prob = std::clamp(grid_prob, 0.0f, 1.0f);
        }

        // 2. Normalize Studio Background Index
        float max_expected_variance = 0.05f; // Flat studio backdrops show low variance
        float bg_index = 1.0f - std::clamp(bg_variance / max_expected_variance, 0.0f, 1.0f);

        // 3. Compute final Joint Commercial Monetization Index
        float raw_index = (word_density * 0.45f) + (grid_prob * 0.35f) + (bg_index * 0.20f);
        raw_index = std::clamp(raw_index, 0.0f, 1.0f);

        // 4. Calculate dynamic retail context risk multiplier (M_retail)
        float multiplier = 1.0f;
        int flag = 0; // None

        if (raw_index >= 0.70f) {
            multiplier = 0.40f; // High confidence commercial listing, apply 60% discount to safety checks
            flag = 2;          // Whitelisted Store Context
        } else if (raw_index >= 0.45f) {
            multiplier = 0.65f; // Suggestive / Potential product catalog
            flag = 1;          // Product Listing
        }

        RetailMetricsOutput output;
        output.commercial_word_density = word_density;
        output.studio_background_index = bg_index;
        output.catalog_grid_probability = grid_prob;
        output.dynamic_retail_multiplier = multiplier;
        output.commercial_flag = flag;

        return output;
    }
};

static CommercialIntentSolver global_intent_solver;
static RetailMetricsOutput global_output_metrics;

extern "C" {
    __attribute__((import_name("onRetailMetricsResolved"))) void onConfidenceCalibrated(RetailMetricsOutput* output);

    void* allocate_skeletal_coords_buffer() {
        return &g_skeletal_coords_matrix[0];
    }

    void* allocate_object_boxes_buffer() {
        return &g_detected_object_boxes[0];
    }

    void* allocate_person_mask_buffer(int size) {
        if (size > MAX_MASK_SIZE) return nullptr;
        return &g_person_mask_buffer[0];
    }

    void* allocate_text_buffer() {
        return &g_retail_text_buffer[0];
    }

    void process_commercial_evaluation(int obj_count, float word_density, float bg_variance, float distance_meters) {
        RetailMetricsOutput results = global_intent_solver.Solve(
            &g_skeletal_coords_matrix[0], 
            &g_detected_object_boxes[0], 
            obj_count, 
            word_density, 
            bg_variance,
            distance_meters
        );
        global_output_metrics = results;
        onConfidenceCalibrated(&global_output_metrics);
    }
}
```

### 3.2 WebGPU Studio Background Shader (`catalog_layout_reducer.wgsl`)
The following WGSL compute shader performs parallel pixel-level segmentation analysis on the GPU to verify if the background matches a flat, solid-color studio drop:

```wgsl
struct SystemConfig {
    width: u32,
    height: u32,
    patch_dimension: u32,
    padding: u32,
};

@group(0) @binding(0) var<uniform> config: SystemConfig;
@group(0) @binding(1) var<storage, read> raw_frame_buffer: array<u32>; // W_frame * H_frame packed RGBA
@group(0) @binding(2) var<storage, read> person_segmentation_mask: array<u32>; // 1 = Person, 0 = Background
@group(0) @binding(3) var<storage, read_write> output_chroma_variance_map: array<f32>;

fn get_pixel_chroma(x: i32, y: i32) -> vec2<f32> {
    let clamp_x = clamp(x, 0, i32(config.width) - 1);
    let clamp_y = clamp(y, 0, i32(config.height) - 1);
    let index = u32(clamp_y) * config.width + u32(clamp_x);
    let packed_rgb = raw_frame_buffer[index];
    
    let r = f32((packed_rgb >> 24u) & 0xffu) / 255.0;
    let g = f32((packed_rgb >> 16u) & 0xffu) / 255.0;
    let b = f32((packed_rgb >> 8u) & 0xffu) / 255.0;
    
    // Convert to YCbCr chrominance coordinates (Cb, Cr)
    let cb = -0.1687 * r - 0.3313 * g + 0.5 * b + 0.5;
    let cr = 0.5 * r - 0.4187 * g - 0.0813 * b + 0.5;

    return vec2<f32>(cb, cr);
}

@compute @workgroup_size(16, 16)
fn main(@builtin(global_invocation_id) global_id: vec3<u32>) {
    let x = i32(global_id.x);
    let y = i32(global_id.y);

    if (x >= i32(config.width) - 2 || y >= i32(config.height) - 2 || x <= 1 || y <= 1) {
        return;
    }

    let index = u32(y) * config.width + u32(x);

    // Only analyze the background region to verify studio drop uniformity
    if (person_segmentation_mask[index] == 1u) {
        return;
    }

    // Solve local chroma variance over a 5x5 spatial window
    var mean_chroma = vec2<f32>(0.0, 0.0);
    var count: f32 = 0.0;

    for (var dy: i32 = -2; dy <= 2; dy++) {
        for (var dx: i32 = -2; dx <= 2; dx++) {
            mean_chroma += get_pixel_chroma(x + dx, y + dy);
            count += 1.0;
        }
    }
    mean_chroma = mean_chroma / count;

    var variance_sum: f32 = 0.0;
    for (var dy: i32 = -2; dy <= 2; dy++) {
        for (var dx: i32 = -2; dx <= 2; dx++) {
            let chroma = get_pixel_chroma(x + dx, y + dy);
            let diff = chroma - mean_chroma;
            variance_sum += dot(diff, diff);
        }
    }

    let local_variance = variance_sum / count;

    let patch_x = x % i32(config.patch_dimension);
    let patch_y = y % i32(config.patch_dimension);
    let output_index = u32(patch_y) * config.patch_dimension + u32(patch_x);

    output_chroma_variance_map[output_index] = local_variance;
}
```

### 3.3 TypeScript Orchestrator Wrapper (`CommercialMonetizationEngine.ts`)
The TypeScript driver manages WebAssembly memory mappings, coordinates parallel WebGPU background chroma variance dispatches, and executes dynamic classifier overrides on device:

```typescript
export interface RetailContextResult {
  readonly commercialWordDensity: number; // W_retail_lex
  readonly studioBackgroundIndex: number; // 1.0 - sigma^2_studio
  readonly catalogGridProbability: number; // L_catalog_layout
  readonly dynamicRetailMultiplier: number; // M_retail
  readonly commercialFlag: 'NONE' | 'PRODUCT_LISTING' | 'STORE_CONTEXT';
}

export class CommercialMonetizationEngine {
  private wasmInstance!: any;
  private memory!: WebAssembly.Memory;
  private bufferOffsetCoords: number = 0;
  private bufferOffsetBoxes: number = 0;
  private bufferOffsetPersonMask: number = 0;
  private bufferOffsetText: number = 0;
  private isLoaded: boolean = false;
  private device!: GPUDevice;
  private pipeline!: GPUComputePipeline;
  private patchDimension = 128;
  private maxObjects = 12;
  private maxMaskSize = 1920 * 1080; // Stable allocation bounds

  private latestResults: RetailContextResult | null = null;

  constructor() {}

  public async initialize(wasmArrayBuffer: ArrayBuffer): Promise<void> {
    const wasmImports = {
      env: {
        onRetailMetricsResolved: (metricsPtr: number) => {
          this.handleResolvedMetrics(metricsPtr);
        }
      }
    };

    const compiled = await WebAssembly.instantiate(wasmArrayBuffer, wasmImports);
    this.wasmInstance = compiled.instance.exports;
    this.memory = this.wasmInstance.memory;
    
    // Allocate stable, aligned buffers on WebAssembly heap safely using C++ exports
    this.bufferOffsetCoords = this.wasmInstance.allocate_skeletal_coords_buffer();
    this.bufferOffsetBoxes = this.wasmInstance.allocate_object_boxes_buffer();
    this.bufferOffsetPersonMask = this.wasmInstance.allocate_person_mask_buffer(this.maxMaskSize);
    this.bufferOffsetText = this.wasmInstance.allocate_text_buffer();

    if (this.bufferOffsetCoords === 0 || this.bufferOffsetBoxes === 0 || this.bufferOffsetText === 0 || this.bufferOffsetPersonMask === 0) {
      throw new Error("WASM Memory allocation failed for commercial analysis buffers");
    }

    // Initialize WebGPU context
    const adapter = await navigator.gpu?.requestAdapter();
    this.device = await adapter?.requestDevice() as GPUDevice;

    const shaderModule = this.device.createShaderModule({
      code: `
        // WGSL code loaded from catalog_layout_reducer.wgsl
      `
    });

    this.pipeline = this.device.createComputePipeline({
      layout: 'auto',
      compute: {
        module: shaderModule,
        entryPoint: 'main'
      }
    });

    this.isLoaded = true;
  }

  public async evaluateRetailContext(
    rawPixelBuffer: Uint32Array,
    personMask: Uint32Array,
    poseLandmarks: Float32Array, // 33 * 4 values
    detectedObjects: Array<{ class_id: number; x_min: number; x_max: number; y_min: number; y_max: number; confidence: number }>,
    surroundingPageText: string,
    width: number,
    height: number
  ): Promise<RetailContextResult | null> {
    if (!this.isLoaded || !this.device) return null;

    // Guard against dynamic inputs exceeding allocated heap bounds (Vulnerability Guard)
    if (personMask.length > this.maxMaskSize) {
       console.warn("Input mask exceeds active buffer allocations, degrading safely.");
       return {
         commercialWordDensity: 0.0,
         studioBackgroundIndex: 0.0,
         catalogGridProbability: 0.0,
         dynamicRetailMultiplier: 1.0,
         commercialFlag: 'NONE'
       };
    }

    // Configure WebGPU buffers for high-speed parallel background chroma variance tracking
    const configBuffer = this.device.createBuffer({
      size: 16,
      usage: GPUBufferUsage.UNIFORM | GPUBufferUsage.COPY_DST
    });

    const frameBuffer = this.device.createBuffer({
      size: rawPixelBuffer.byteLength,
      usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_DST,
      mappedAtCreation: false
    });

    const maskBuffer = this.device.createBuffer({
      size: personMask.byteLength,
      usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_DST,
      mappedAtCreation: false
    });

    const outputChromaBuffer = this.device.createBuffer({
      size: this.patchDimension * this.patchDimension * 4, // 128 * 128 * sizeof(f32)
      usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_SRC
    });

    // Write parameters to buffers
    const configData = new Uint32Array([width, height, this.patchDimension, 0]);
    this.device.queue.writeBuffer(configBuffer, 0, configData.buffer);
    this.device.queue.writeBuffer(frameBuffer, 0, rawPixelBuffer.buffer);
    this.device.queue.writeBuffer(maskBuffer, 0, personMask.buffer);

    const bindGroup = this.device.createBindGroup({
      layout: this.pipeline.getBindGroupLayout(0),
      entries: [
        { binding: 0, resource: { buffer: configBuffer } },
        { binding: 1, resource: { buffer: frameBuffer } },
        { binding: 2, resource: { buffer: maskBuffer } },
        { binding: 3, resource: { buffer: outputChromaBuffer } }
      ]
    });

    const commandEncoder = this.device.createCommandEncoder();
    const passEncoder = commandEncoder.beginComputePass();
    passEncoder.setPipeline(this.pipeline);
    passEncoder.setBindGroup(0, bindGroup);
    passEncoder.dispatchWorkgroups(Math.ceil(width / 16), Math.ceil(height / 16));
    passEncoder.end();

    const stagingBuffer = this.device.createBuffer({
      size: this.patchDimension * this.patchDimension * 4,
      usage: GPUBufferUsage.COPY_DST | GPUBufferUsage.MAP_READ
    });

    commandEncoder.copyBufferToBuffer(outputChromaBuffer, 0, stagingBuffer, 0, this.patchDimension * this.patchDimension * 4);
    this.device.queue.submit([commandEncoder.finish()]);

    await stagingBuffer.mapAsync(GPUMapMode.READ);
    const localChromaData = new Float32Array(stagingBuffer.getMappedRange());

    // Calculate background chroma variance to pass to the WASM solver
    let varianceSum = 0.0;
    const pixelCount = localChromaData.length;
    for (let i = 0; i < pixelCount; ++i) {
      varianceSum += localChromaData[i];
    }
    const averageChromaVariance = varianceSum / pixelCount;

    stagingBuffer.unmap();

    // Map skeletal coordinate landmarks directly to the WASM heap
    const heapView = new Float32Array(this.memory.buffer, this.bufferOffsetCoords, 33 * 4);
    for (let i = 0; i < 33; ++i) {
      heapView[i * 4] = poseLandmarks[i * 4];         // X
      heapView[i * 4 + 1] = poseLandmarks[i * 4 + 1]; // Y
      heapView[i * 4 + 2] = poseLandmarks[i * 4 + 2]; // Z
      heapView[i * 4 + 3] = poseLandmarks[i * 4 + 3]; // Confidence
    }

    // Map detected objects onto WebAssembly heap
    const objectCount = Math.min(detectedObjects.length, this.maxObjects);
    const heapObjects = new DataView(this.memory.buffer, this.bufferOffsetBoxes, this.maxObjects * 24); // sizeof(BoundingBox) = 24
    for (let i = 0; i < objectCount; ++i) {
      const obj = detectedObjects[i];
      heapObjects.setFloat32(i * 24, obj.x_min, true);
      heapObjects.setFloat32(i * 24 + 4, obj.x_max, true);
      heapObjects.setFloat32(i * 24 + 8, obj.y_min, true);
      heapObjects.setFloat32(i * 24 + 12, obj.y_max, true);
    }

    // Map person mask directly to the WASM heap
    const heapPersonMask = new Uint8Array(this.memory.buffer, this.bufferOffsetPersonMask, personMask.length);
    heapPersonMask.set(personMask);

    // Map surrounding page text to WASM buffer safely
    const encoder = new TextEncoder();
    const encodedText = encoder.encode(surroundingPageText.substring(0, 4095)); // Max 4096 bytes
    const heapText = new Uint8Array(this.memory.buffer, this.bufferOffsetText, 4096);
    heapText.fill(0);
    heapText.set(encodedText);

    // Calculate local commercial keyword density using regular expressions (Offline NLP)
    const commercialKeywords = [/add to cart/i, /checkout/i, /sku/i, /price/i, /usd/i, /discount/i, /buy now/i];
    let matchCount = 0;
    for (const regex of commercialKeywords) {
      if (regex.test(surroundingPageText)) {
        matchCount++;
      }
    }
    const wordDensity = matchCount / commercialKeywords.length;

    // Trigger WASM execution loop with calculated parameters (Correction: Invoked correct signature with distance metrics)
    const mockSubjectDistanceMeters = 2.0;
    this.wasmInstance.process_commercial_evaluation(objectCount, wordDensity, averageChromaVariance, mockSubjectDistanceMeters);

    return this.latestResults;
  }

  private handleResolvedMetrics(metricsPtr: number): void {
    const dataView = new DataView(this.memory.buffer, metricsPtr, 20); // sizeof(RetailMetricsOutput) = 20
    
    const commercialWordDensity = dataView.getFloat32(0, true);
    const studioBackgroundIndex = dataView.getFloat32(4, true);
    const catalogGridProbability = dataView.getFloat32(8, true);
    const dynamicRetailMultiplier = dataView.getFloat32(12, true);
    const commercialFlagInt = dataView.getInt32(16, true);

    let commercialFlag: 'NONE' | 'PRODUCT_LISTING' | 'STORE_CONTEXT' = 'NONE';
    if (commercialFlagInt === 2) {
      commercialFlag = 'STORE_CONTEXT';
    } else if (commercialFlagInt === 1) {
      commercialFlag = 'PRODUCT_LISTING';
    }

    this.latestResults = {
      commercialWordDensity,
      studioBackgroundIndex,
      catalogGridProbability,
      dynamicRetailMultiplier,
      commercialFlag
    };
  }
}
```

## 4. Comprehensive Edge Cases & Mitigations

### 4.1 Fake E-Commerce Overlays (Adversarial Cart Masking)
- **Vulnerability:** Suggestive content networks may overlay fake "Add to Cart" banners, simulated price tags, or artificial catalog grids onto restricted media to bypass filters.
- **Mitigation Strategy:**
  - **Studio Uniformity Check:** Standard product listings utilize perfectly uniform, solid-color studio backdrops ($\sigma^2_{\text{studio}} < 0.02$). Suggestive content pairs typical complex bedroom/domestic environments ($\sigma^2_{\text{variance}} \ge 0.08$) with overlaid buttons.
  - **Action:** If background variance is complex while overlays are detected, the system flags the interaction as a "malicious bypass attempt," disables the commercial exception, and applies standard clothing and pose limits with maximum sensitivity.

### 4.2 Flat-Plane Screen/Paper Projections (Evasion Evasion)
- **Vulnerability:** Suggestive content creators may hold up high-resolution printed photos of clinical diagrams or display medical scans on physical flat screens/mobile devices in front of the lens, attempting to trick on-device trackers.
- **Mitigation Strategy:**
  - **3D Flat-Plane Detection:** Reconstruct joint coordinates over a rolling 15-frame window. While human subjects move in 3D depth planes, printed photos or screen projections are mathematically flat along the optical axis ($Z_{\text{depth}}$ standard deviation $\sigma^2_z < 0.001$).
  - **Action:** If flat-plane projection is detected, immediately lock the system's $S_{\text{safe\_override\_multiplier}}$ to 1.00 (Standard mode) and disable all safe exception overrides.
