## Context
Cyber threat content is harmful when:
1. Providing functional hacking tools
2. Selling stolen credentials
3. Tutorial for illegal access
4. Targeting specific victims

Cyber threat content can be acceptable in:
1. Ethical hacking education (CEH, OSCP context)
2. Bug bounty research
3. Defensive security training
4. Academic security research

Default: BLOCK distribution/services. CONTEXT-CHECK educational content.
