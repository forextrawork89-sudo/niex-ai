# Human Emotion Intelligence Framework

This document is the authoritative foundation for facial expression understanding and emotion intelligence within the emotion subsystem.
It replaces prior implementation-oriented material with a research-grade conceptual framework for human emotion perception, affective reasoning, facial behavior analysis, temporal emotion understanding, contextual interpretation, and explainable multimodal intelligence.
The framework treats facial expression as one component of a much larger human emotion system that includes appraisal, cognition, social coordination, physiology, context, temporal development, and behavioral evidence.
Emotion analysis is never reduced to suggestive-expression detection or to simplistic classification of smiling, frowning, or eye movement alone.
The purpose of this framework is to explain how emotions emerge, how they are visible through facial behavior, how they evolve over time, how context shapes their interpretation, and how uncertainty and confidence should be preserved in high-stakes reasoning.

## 1. Human Emotion Foundations

Affective computing studies how human emotion can be recognized, interpreted, and reasoned about through observable signals and contextual evidence.
Emotion is not a single visible act. It is a layered state involving appraisal, motivational salience, physiology, memory, cultural learning, social meaning, and behavioral expression.
Facial expressions are meaningful because they express the dynamic coordination of musculature, attention, intention, and social signaling.
A reliable emotion framework must distinguish between visible expression, inferred emotion, emotional state, emotional episode, display rules, and social interpretation.

### 1.1 Affective Computing

Affective computing examines the study of human affective states through observable and inferential forms of evidence.
It incorporates facial behavior, vocal cues, posture, gesture, context, and temporal structure.
The field requires explainable reasoning because affective interpretation is probabilistic, culturally shaped, and often ambiguous.

### 1.2 Emotion Theory

Emotion theory explains the structure of emotional life and the difference between basic states, socially constructed states, motivational states, and bodily feelings.
It recognizes that emotion can be viewed as discrete, dimensional, componential, and socially situated.
No single theory explains all emotional phenomena, so an authoritative framework integrates multiple perspectives.

### 1.3 Appraisal Theory

Appraisal theory explains that emotions arise when people evaluate events relative to goals, values, agency, control, novelty, and social implications.
A person may show similar facial behavior for different emotions depending on whether the event is appraised as threatening, unfair, desirable, or meaningful.
This theory is essential for explaining why the same expression can align with different emotional interpretations under different circumstances.
* 1.3.1: Appraisal case 1 showing how a meaningful event produces facial and behavioral evidence of emotion.
* 1.3.2: Appraisal case 2 showing how a meaningful event produces facial and behavioral evidence of emotion.

### 1.4 Constructivist Emotion Theory

Constructivist emotion theory argues that emotion categories are shaped by language, culture, social learning, and context.
It emphasizes the role of conceptualization in forming emotion experiences and in interpreting expressive behavior.
Facial movement remains important, but its meaning is not fixed across all persons and settings.
* 1.4.1: Constructivist case 1 showing how social context changes the interpretation of facial behavior.
* 1.4.2: Constructivist case 2 showing how social context changes the interpretation of facial behavior.

### 1.5 Basic Emotion Theory

Basic emotion theory posits that some emotions are highly recognizable and may have strong cross-cultural signatures.
It remains valuable for organizing visible patterns such as fear, anger, sadness, disgust, joy, and surprise.
The framework uses basic emotion theory as one layer of explanation without reducing all emotion understanding to a small set of basic states.
* 1.5.1: Basic emotion case 1 showing how a clearly visible facial pattern may support a broad emotion inference.

### 1.6 Dimensional Emotion Theory

Dimensional emotion theory models emotions according to valence, arousal, dominance, control, and intensity.
It is critical for representing nuanced emotional states such as calm concern, tense curiosity, bittersweet relief, or anxious confidence.
Dimensional models complement discrete emotion labels by preserving graded intensity and mixed affective states.

## 2. Emotion Taxonomy

The emotion taxonomy organizes facially visible affective states into positive, negative, cognitive, social, and physical domains.
This taxonomy is not a rigid label set. It is a structured ontology that preserves observable facial evidence, contextual evidence, temporal behavior, and ambiguity factors.

To ensure deterministic, high-frequency evaluations within sandboxed background workers, the engine maps the 468 3D landmarks (x,y,z) into normalized scalar contraction indices ($AU_i \in [0.0, 1.0]$).

Let $D(p_1, p_2)$ represent the standard Euclidean distance between two 3D spatial points within the mesh workspace:

$$D(p_1, p_2) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

The system computes four core muscle contraction matrices using baseline normalization vectors to control for camera distance variations:

**AU01 (Inner Brow Raiser Intensity):** Tracks vertical movement of the inner brow relative to the glabella region:

$$\text{Raw}_{AU01} = \frac{D(P_{10}, P_{152}) + \epsilon}{D(P_{65}, P_{152})}$$

$$\text{Raw}_{AU02} = \frac{D(P_{10}, P_{152}) + \epsilon}{D(P_{70}, P_{276})}$$

**AU12 (Lip Corner Puller Intensity):** Measures the lateral stretching and upward pull of the mouth corners:

$$\text{Raw}_{AU12} = \frac{D(P_{33}, P_{263}) + \epsilon}{D(P_{57}, P_{287})}$$

$$\text{Raw}_{AU26} = D(P_{13}, P_{14})$$

Each raw extraction value is clamped and normalized using empirical operational thresholds:

$$AU_i = \max\left(0.0, \min\left(1.0, \frac{\text{Raw}_{AU_i} - \tau_{\min\_i}}{\tau_{\max\_i} - \tau_{\min\_i}}\right)\right)$$

### 2.2 Combined Expression Intensity Score Formulation ($S_{\text{expression}}$)

The final expression risk score $S_{\text{expression}} \in [0, 100]$ is calculated as a dynamically weighted sum of active muscle states:

$$S_{\text{expression}} = \left( \frac{\sum_{i \in \{1,2,4,12,26\}} AU_i \cdot W_i}{\sum_{i \in \{1,2,4,12,26\}} W_i} \right) \times 100.0$$

Where the static protection weights are defined to prioritize structural indicators: $W_{01} = 1.0, W_{02} = 1.0, W_{04} = 1.5, W_{12} = 2.5,$ and $W_{26} = 3.0$.

```javascript
/**
 * ============================================================================
 * AI RADAR SYSTEM - SCENE UNDERSTANDING SUBSYSTEM
 * MODULE: FACIAL_EXPRESSION_METRICS_ENGINE
 * VERSION: 16.5.0-RELEASE-PROD-SHIELD
 * CHROMIUM MV3 BACKGROUND EXTENSION WORKER CORE - ZERO RUNTIME HEAP ALLOCATION
 * ============================================================================
 */

"use strict";

const FACS_SHIELD_CONFIG = {
    IDENTIFIER: "AI_RADAR_LOCAL_SU_FACIAL_EXPRESSION_METRICS",
    WEIGHT_AU01: 1.0,
    WEIGHT_AU02: 1.0,
    WEIGHT_AU04: 1.5,
    WEIGHT_AU12: 2.5,
    WEIGHT_AU26: 3.0,
    TAU_SUGGESTIVE_LIMIT: 60.0,
    TAU_DISTRESS_LIMIT: 75.0,
    EPSILON: 0.000001
};

class FacialExpressionMetricsEngine {
    constructor() {
        this.evaluatedFramesCounter = 0n;
        
        // Pre-allocated typed arrays to preserve memory blocks across execution loops
        this.actionUnitIntensityBuffer = new Float32Array(5); // [AU01, AU02, AU04, AU12, AU26]
        this.distanceScratchPad = new Float32Array(3); // Temporary calculation cache
    }

    /**
     * Parses raw face mesh tracking nodes, resolves muscle intensities, and generates system threat profiles.
     * @param {Array} faceMesh3DLandmarks - Array containing 468 normalized landmark objects {x, y, z}.
     * @returns {Object} Complete emotional metrics and security directive payload.
     */
    evaluateFacialMetrics(faceMesh3DLandmarks) {
        this.evaluatedFramesCounter++;

        if (!faceMesh3DLandmarks || faceMesh3DLandmarks.length < 468) {
            return this._triggerSecureExceptionFallback("FACE_MESH_STREAM_UNAVAILABLE_OR_INCOMPLETE");
        }

        // 1. Structural Distance Extraction with Scaling Normalization
        const scaleBase = this._computeEuclideanDistance3D(faceMesh3DLandmarks[10], faceMesh3DLandmarks[152]);
        const widthBase = this._computeEuclideanDistance3D(faceMesh3DLandmarks[33], faceMesh3DLandmarks[263]);
        
        const normScale = scaleBase > 0 ? scaleBase : 1.0;
        const normWidth = widthBase > 0 ? widthBase : 1.0;

        // AU01 : Inner Brow Raiser (Landmarks 65, 152)
        const rawAU01 = this._computeEuclideanDistance3D(faceMesh3DLandmarks[65], faceMesh3DLandmarks[152]) / normScale;
        this.actionUnitIntensityBuffer[0] = Math.max(0.0, Math.min(1.0, (rawAU01 - 0.82) / 0.15));

        // AU02 : Outer Brow Raiser (Landmarks 70, 276)
        const rawAU02 = this._computeEuclideanDistance3D(faceMesh3DLandmarks[70], faceMesh3DLandmarks[276]) / normScale;
        this.actionUnitIntensityBuffer[1] = Math.max(0.0, Math.min(1.0, (rawAU02 - 0.42) / 0.12));

        // AU04 : Brow Lowerer (Glabella Compression Link, Landmarks 9, 223)
        const rawAU04 = this._computeEuclideanDistance3D(faceMesh3DLandmarks[9], faceMesh3DLandmarks[223]) / normWidth;
        this.actionUnitIntensityBuffer[2] = Math.max(0.0, Math.min(1.0, (0.35 - rawAU04) / 0.10)); // Compression inverted

        // AU12 : Lip Corner Puller (Landmarks 57, 287)
        const rawAU12 = this._computeEuclideanDistance3D(faceMesh3DLandmarks[57], faceMesh3DLandmarks[287]) / normWidth;
        this.actionUnitIntensityBuffer[3] = Math.max(0.0, Math.min(1.0, (rawAU12 - 0.48) / 0.22));

        // AU26 : Jaw Drop (Absolute Vertical Separation, Landmarks 13, 14)
        const rawAU26 = this._computeEuclideanDistance3D(faceMesh3DLandmarks[13], faceMesh3DLandmarks[14]);
        this.actionUnitIntensityBuffer[4] = Math.max(0.0, Math.min(1.0, rawAU26 / 0.08));

        // 2. Weighted Matrix Summation to Derive S_expression
        const weightedSum = (this.actionUnitIntensityBuffer[0] * FACS_SHIELD_CONFIG.WEIGHT_AU01) +
                            (this.actionUnitIntensityBuffer[1] * FACS_SHIELD_CONFIG.WEIGHT_AU02) +
                            (this.actionUnitIntensityBuffer[2] * FACS_SHIELD_CONFIG.WEIGHT_AU04) +
                            (this.actionUnitIntensityBuffer[3] * FACS_SHIELD_CONFIG.WEIGHT_AU12) +
                            (this.actionUnitIntensityBuffer[4] * FACS_SHIELD_CONFIG.WEIGHT_AU26);

        const totalWeight = FACS_SHIELD_CONFIG.WEIGHT_AU01 + FACS_SHIELD_CONFIG.WEIGHT_AU02 +
                            FACS_SHIELD_CONFIG.WEIGHT_AU04 + FACS_SHIELD_CONFIG.WEIGHT_AU12 +
                            FACS_SHIELD_CONFIG.WEIGHT_AU26;

        const calculatedExpressionScore = (weightedSum / totalWeight) * 100.0;

        // 3. Resolve Execution Profile Classification Paths
        let targetExpressionProfile = "PROFESSIONAL_NEUTRAL";
        let parallelSensitivityEscalationRequired = false;
        let systemActionVerdict = "PASS";

        if (calculatedExpressionScore > FACS_SHIELD_CONFIG.TAU_SUGGESTIVE_LIMIT) {
            if (this.actionUnitIntensityBuffer[3] >= 0.55 && this.actionUnitIntensityBuffer[4] >= 0.40) {
                targetExpressionProfile = "SUGGESTIVE_EXPLICIT_EXPOSURE";
                parallelSensitivityEscalationRequired = true; // Trigger downstream modifier adjustments
                systemActionVerdict = "ENFORCE_SENSITIVITY_MODIFIER";
            } else if (this.actionUnitIntensityBuffer[2] >= 0.70 && this.actionUnitIntensityBuffer[4] >= 0.60) {
                targetExpressionProfile = "TRAUMA_DISTRESS_ALERT";
                systemActionVerdict = "REDIRECT_TO_SAFETY_LOGS";
            }
        }

        return {
            statusSecure: true,
            signaturePayload: FACS_SHIELD_CONFIG.IDENTIFIER,
            cycleIndex: this.evaluatedFramesCounter,
            expressionIntensityScore: calculatedExpressionScore,
            resolvedProfile: targetExpressionProfile,
            escalateParallelFilters: parallelSensitivityEscalationRequired,
            actionVerdict: systemActionVerdict,
            actionUnitTelemetry: {
                au01_innerBrow: this.actionUnitIntensityBuffer[0],
                au02_outerBrow: this.actionUnitIntensityBuffer[1],
                au04_glabellaComp: this.actionUnitIntensityBuffer[2],
                au12_lipCornerPull: this.actionUnitIntensityBuffer[3],
                au26_jawDrop: this.actionUnitIntensityBuffer[4]
            }
        };
    }

    /**
     * Calculates spatial line length intervals between target landmarks.
     * @private
     */
    _computeEuclideanDistance3D(point1, point2) {
        this.distanceScratchPad[0] = point1.x - point2.x;
        this.distanceScratchPad[1] = point1.y - point2.y;
        this.distanceScratchPad[2] = point1.z - point2.z;

        return Math.sqrt(
            this.distanceScratchPad[0] * this.distanceScratchPad[0] +
            this.distanceScratchPad[1] * this.distanceScratchPad[1] +
            this.distanceScratchPad[2] * this.distanceScratchPad[2]
        );
    }

    /**
     * Fail-safe routing template fallback block.
     * @private
     */
    _triggerSecureExceptionFallback(faultString) {
        console.error(`[FACIAL_EXPRESSION_METRICS_CRITICAL_FAULT] ${faultString}`);
        return {
            statusSecure: false,
            signaturePayload: FACS_SHIELD_CONFIG.IDENTIFIER,
            cycleIndex: this.evaluatedFramesCounter,
            expressionIntensityScore: 100.0, // Force maximum risk score to prevent security leakage
            resolvedProfile: "EMERGENCY_OVERRIDE_PROTECTION",
            escalateParallelFilters: true,
            actionVerdict: "FORCE_PREEMPTIVE_HARD_BLOCK", // Enforce strict safety override on errors
            telemetryFault: faultString
        };
    }
}

if (typeof module !== "undefined" && module.exports) {

    self.FacialExpressionMetricsEngineInstance = new FacialExpressionMetricsEngine();
```
