# Classical Art Educational Intelligence Framework

This document is the authoritative specification for classical-art interpretation within the educational subsystem.
It replaces prior implementation-oriented material with a research-grade conceptual framework for identifying classical art, understanding artistic intent, interpreting historical significance, evaluating educational relevance, preserving cultural heritage context, and supporting explainable multimodal reasoning.
Classical art is treated as a historically grounded, culturally specific, and educationally consequential domain of visual expression rather than as a simple exception category or a generic visual pattern.
The purpose of this framework is to explain how classical art should be recognized, how it contributes to educational context, how historical significance influences interpretation, how artistic intent differs from ordinary visual content, and how classical art reduces false positives.

## 1. Classical Art Foundations

Classical art requires specialized interpretation because it is shaped by historical method, cultural memory, institutional framing, restoration history, educational use, and aesthetic tradition.
A proper framework must distinguish between artwork, image, object, archive reference, museum display, educational reproduction, and decorative adaptation.
The framework preserves the difference between a genuine historical artwork, a reproduction, a stylized derivative, a restoration study, and a contemporary homage.

### 3.1 Material Reflectance and Color Variance ($\Lambda_{\text{art}}$)

Classical statues and sculptures made of marble, bronze, clay, or plaster display unique, highly uniform color-space variance values compared to human skin. Let $R_{\text{variance}}$ be the spatial chroma variance computed over the segmented subject mask $M_{\text{person}}$:

$$R_{\text{variance}} = \frac{1}{N} \sum_{i=0}^{N-1} \|(Cb_i, Cr_i) - (\bar{Cb}, \bar{Cr})\|^2$$

Where $(Cb, Cr)$ represents the chrominance coordinates in YCbCr color space.

The **Material Reflectance Index ($\Lambda_{\text{art}}$)** is calculated on device as:
$$\Lambda_{\text{art}} = \left( 1.0 - R_{\text{variance}} \right) \cdot \Phi_{\text{reflectance}} \cdot \Phi_{\text{distance\_norm}}$$

*   $\Phi_{\text{reflectance}}$ is the specular reflectance coefficient computed by the local WebGPU shader. Marble and bronze sculptures exhibit extremely low chroma variance ($R_{\text{variance}} < 0.02$), which results in a high $\Lambda_{\text{art}}$ score ($> 0.85$).

*   $\Phi_{\text{distance\_norm}}$ is the scale-invariant dynamic distance normalization factor to prevent false positive triggers on distant, blurry subjects (derived from `distance_patterns/`).

### 3.2 3D Skeletal Shape-Matching Index ($S_{\text{match}}$)

To verify if a subject's posture corresponds with classical museum poses, the system measures the cosine similarity between the current 3D joint coordinate link vectors $V_i$ and a pre-defined set of historical art posture templates $T_i$:

$$S_{\text{match}} = \frac{1}{K} \sum_{i=1}^{K} \frac{V_i \cdot T_i}{\|V_i\| \|T_i\|}$$

If $S_{\text{match}}$ exceeds $0.88$ while $\Lambda_{\text{art}}$ is high, the skeletal shape is verified as a classical sculpture, bypassing standard body-shape filters.

public:
    static float ComputeSimilarity(const Point3D* current, const Point3D* art_template) {
        float dot_product_sum = 0.0f;
        float norm_current_sum = 0.0f;
        float norm_template_sum = 0.0f;

            {11, 23}, {12, 24}, {11, 12}, {23, 24}
        };

            int u = joint_links[i][0];
            int v = joint_links[i][1];

            float dx_c = current[v].x - current[u].x;
            float dy_c = current[v].y - current[u].y;
            float dz_c = current[v].z - current[u].z;

            float dx_t = art_template[v].x - art_template[u].x;
            float dy_t = art_template[v].y - art_template[u].y;
            float dz_t = art_template[v].z - art_template[u].z;

            dot_product_sum += dx_c * dx_t + dy_c * dy_t + dz_c * dz_t;
            norm_current_sum += dx_c * dx_c + dy_c * dy_c + dz_c * dz_c;
            norm_template_sum += dx_t * dx_t + dy_t * dy_t + dz_t * dz_t;
        }

        float denominator = sqrt(norm_current_sum) * sqrt(norm_template_sum);
        return (denominator > 0.0f) ? (dot_product_sum / denominator) : 0.0f;
    }
};

    width: u32,
    height: u32,
    patch_dimension: u32,
    padding: u32,

@group(0) @binding(1) var<storage, read> raw_frame_buffer: array<u32>; // W_frame * H_frame packed RGBA
@group(0) @binding(2) var<storage, read_write> output_reflectance_map: array<f32>;

fn get_pixel_chroma(x: i32, y: i32) -> vec2<f32> {
    let clamp_x = clamp(x, 0, i32(config.width) - 1);
    let clamp_y = clamp(y, 0, i32(config.height) - 1);
    let index = u32(clamp_y) * config.width + u32(clamp_x);
    let packed_rgb = raw_frame_buffer[index];
    
    // Extract RGB channels
    let r = f32((packed_rgb >> 24u) & 0xffu) / 255.0;
    let g = f32((packed_rgb >> 16u) & 0xffu) / 255.0;
    let b = f32((packed_rgb >> 8u) & 0xffu) / 255.0;
    
    // Convert to YCbCr chrominance coordinates (Cb, Cr)
    let cb = -0.1687 * r - 0.3313 * g + 0.5 * b + 0.5;
    let cr = 0.5 * r - 0.4187 * g - 0.0813 * b + 0.5;

    return vec2<f32>(cb, cr);
}

@compute @workgroup_size(16, 16)
fn main(@builtin(global_invocation_id) global_id: vec3<u32>) {
    let x = i32(global_id.x);
    let y = i32(global_id.y);

    if (x >= i32(config.width) - 2 || y >= i32(config.height) - 2 || x <= 1 || y <= 1) {
        return;
    }

    // Solve local chroma variance over a 5x5 window
    var mean_chroma = vec2<f32>(0.0, 0.0);
    var count: f32 = 0.0;

    for (var dy: i32 = -2; dy <= 2; dy++) {
        for (var dx: i32 = -2; dx <= 2; dx++) {
            mean_chroma += get_pixel_chroma(x + dx, y + dy);
            count += 1.0;
        }
    }
    mean_chroma = mean_chroma / count;

    var variance_sum: f32 = 0.0;
    for (var dy: i32 = -2; dy <= 2; dy++) {
        for (var dx: i32 = -2; dx <= 2; dx++) {
            let chroma = get_pixel_chroma(x + dx, y + dy);
            let diff = chroma - mean_chroma;
            variance_sum += dot(diff, diff);
        }
    }

    let local_variance = variance_sum / count;

    // Stone and metal sculptures display extremely low chroma variance
    var reflectance: f32 = 0.0;
    if (local_variance < 0.02) {
        reflectance = 1.0 - (local_variance / 0.02);
    }

    let patch_x = x % i32(config.patch_dimension);
    let patch_y = y % i32(config.patch_dimension);
    let output_index = u32(patch_y) * config.patch_dimension + u32(patch_x);

    output_reflectance_map[output_index] = reflectance;
}

    passEncoder.end();

    const stagingBuffer = this.device.createBuffer({

    });

    this.device.queue.submit([commandEncoder.finish()]);

    await stagingBuffer.mapAsync(GPUMapMode.READ);

    // Map skeletal coordinate landmarks directly to the WASM heap

      heapView[i * 4 + 3] = poseLandmarks[i * 4 + 3]; // Confidence

    const heapReflectance = new Float32Array(this.memory.buffer, this.bufferOffsetReflectance, this.patchDimension * this.patchDimension);

    stagingBuffer.unmap();

  private handleResolvedMetrics(metricsPtr: number): void {

## 5. Comprehensive Edge Cases & Mitigations

### 5.1 Staged Interactive Poses (Adversarial Pose Copycatting)
**Vulnerability:** Live subjects can copycat contrapposto poses or reclining shapes matching the sculpture templates while wearing low-coverage garments, attempting to bypass standard limits.

**Mitigation Strategy:**
*   **Chroma Variance Gate:** Human skin under stable illumination exhibits dynamic, localized chromatic variance ($R_{\text{variance}} \ge 0.05$ inside the segmented mask).
*   **High-frequency Texture Check:** Live subjects display natural hair and fabric borders, whereas stone/marble sculptures exhibit completely uniform gray-scale luminance properties ($\Lambda_{\text{art}} \ge 0.85$). If the chroma variance is high, the system automatically classifies the subject as a live copycat and ignores the art exception, applying standard clothing rules.

### 5.2 Flat-Plane Screen/Paper Projections (Evasion Evasion)
**Vulnerability:** Suggestive content creators may hold up high-resolution printed photos or display video projections of classical sculptures in front of the lens to trick the material and shape classifiers into applying safe bypasses.

**Mitigation Strategy:**
*   **3D Flat-Plane Detection:** Reconstruct joint coordinates over a rolling 15-frame window. While human subjects move in 3D depth planes, printed photos or screen projections are mathematically flat along the optical axis ($Z_{\text{depth}}$ standard deviation $\sigma_z^2 < 0.001$).
*   **Action:** If flat-plane projection is detected, immediately lock the system's `S_safe_override_multiplier` to 1.00 (Standard mode) and disable all safe exception overrides.

### 6.1 Camera Perspective Distortion Compensation
Foreshortening effects distort the boundary shape when the subject leans relative to the optical plane. To correct these distortions, the C++ normalizer maps the coordinates against the camera's intrinsic calibration parameters before running the Fourier transform calculations:
