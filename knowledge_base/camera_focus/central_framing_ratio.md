### 3.1 Centroid Offset ($C_{\text{offset}}$)

Let $(X_{\text{person\_center}}, Y_{\text{person\_center}})$ be the calculated 2D centroid of the subject's person mask $M_{\text{person}}$, and $(X_{\text{frame\_center}}, Y_{\text{frame\_center}})$ be the geometric center of the frame.

The **Centroid Offset ($C_{\text{offset}}$)** is calculated in pixels as:

$$C_{\text{offset}} = \sqrt{(X_{\text{person\_center}} - X_{\text{frame\_center}})^2 + (Y_{\text{person\_center}} - Y_{\text{frame\_center}})^2}$$

Where the person center coordinates are resolved by calculating the local center of mass:
$$X_{\text{person\_center}} = \frac{1}{\text{Area}_{\text{person}}} \sum_{i=0}^{N-1} x_i, \quad Y_{\text{person\_center}} = \frac{1}{\text{Area}_{\text{person}}} \sum_{i=0}^{N-1} y_i$$

### 3.2 Central Framing Ratio ($R_{\text{frame}}$)

The **Central Framing Ratio ($R_{\text{frame}}$)** measures the percentage area occupied by the subject relative to the total frame area:

$$R_{\text{frame}} = \frac{\text{Area}_{\text{person}}}{\text{Area}_{\text{frame}}}$$

Where $\text{Area}_{\text{frame}} = \text{width} \cdot \text{height}$ of the incoming video stream. High values of $R_{\text{frame}}$ ($\ge 0.50$) combined with low $C_{\text{offset}}$ indicate extreme center focus, typical of portrait-mode close-ups.

### 4.1 C++ WebAssembly Centering Solver (`central_framing_solver.cpp`)
The following C++ engine compiles directly to WebAssembly with SIMD and auto-vectorization enabled. It handles bounding box coordinate tracking, centroid offset calculations, and dynamic framing ratio evaluations:

```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>
#include <memory>
#include <cstring>

#if defined(__wasm__) && defined(__ARM_NEON)
#include <arm_neon.h>
#elif defined(__wasm__) && defined(__SSE2__)
#include <emmintrin.h>
#endif

constexpr int SKELETAL_COORDS_COUNT = 33;
constexpr int HISTORY_BUFFER_SIZE = 15;
constexpr int MAX_MASK_SIZE = 1048576; // 1024 * 1024 max mask resolution (Safe Buffer)

struct Point3D {
    float x;
    float y;
    float z;
    float confidence;
};

struct FramingMetricsOutput {
    float central_framing_ratio;  // R_frame
    float centroid_offset_pixels; // C_offset
    float raw_subject_area;       // Area_person
    int framing_classification;   // 0 = Wide Scenery, 1 = Standard Portrait, 2 = Extreme Center Focus
    float confidence;
};

// Global memory buffers mapped to WebAssembly Linear Memory Heap
Point3D g_skeletal_coords_matrix[SKELETAL_COORDS_COUNT];
uint8_t g_person_mask_buffer[MAX_MASK_SIZE];

// Double Exponential Smoothing Filter for the output framing ratio over time
class TemporalDoubleSmoother {
public:
    TemporalDoubleSmoother() : is_initialized_(false), alpha_(0.70f), beta_(0.20f) {}

    float Apply(float raw_value) {
        if (!is_initialized_) {
            s_ = raw_value;
            b_ = 0.0f;
            is_initialized_ = true;
            return raw_value;
        }

        float prev_s = s_;
        s_ = alpha_ * raw_value + (1.0f - alpha_) * (s_ + b_);
        b_ = beta_ * (s_ - prev_s) + (1.0f - beta_) * b_;
        return s_;
    }

    void Reset() {
        is_initialized_ = false;
    }

private:
    bool is_initialized_;
    float alpha_;
    float beta_;
    float s_;
    float b_;
};

class CentralFramingSolver {
public:
    CentralFramingSolver() {
        ratio_smoother_.Reset();
        offset_smoother_.Reset();
    }
    ~CentralFramingSolver() = default;

    FramingMetricsOutput Solve(const uint8_t* person_mask, int width, int height) {
        int total_person_pixels = 0;
        float centroid_x_sum = 0.0f;
        float centroid_y_sum = 0.0f;

        int size = width * height;
        if (size > MAX_MASK_SIZE) {
            return {0.0f, 0.0f, 0.0f, 0, 0.0f}; // Guard heap allocation
        }

        // 1. Calculate centroid and active pixel area in parallel
        int simd_limit = (size / 16) * 16;
#if defined(__wasm__) && defined(__SSE2__)
        for (int i = 0; i < simd_limit; i += 16) {
            __m128i p_chunk = _mm_loadu_si128((const __m128i*)&person_mask[i]);
            __m128i zero = _mm_setzero_si128();
            __m128i p_gt = _mm_gt_epi8(p_chunk, zero);

            alignas(16) uint8_t res[16];
            _mm_storeu_si128((__m128i*)res, p_gt);

            for (int k = 0; k < 16; ++k) {
                if (res[k] != 0) {
                    int idx = i + k;
                    int x = idx % width;
                    int y = idx / width;
                    centroid_x_sum += static_cast<float>(x);
                    centroid_y_sum += static_cast<float>(y);
                    total_person_pixels++;
                }
            }
        }
        for (int i = simd_limit; i < size; ++i) {
            if (person_mask[i] == 1) {
                centroid_x_sum += static_cast<float>(i % width);
                centroid_y_sum += static_cast<float>(i / width);
                total_person_pixels++;
            }
        }
#else
        for (int i = 0; i < size; ++i) {
            if (person_mask[i] == 1) {
                centroid_x_sum += static_cast<float>(i % width);
                centroid_y_sum += static_cast<float>(i / width);
                total_person_pixels++;
            }
        }
#endif

        if (total_person_pixels <= 16) {
            return {0.0f, 0.0f, 0.0f, 0, 0.0f}; // Subject is empty
        }

        float p_center_x = centroid_x_sum / total_person_pixels;
        float p_center_y = centroid_y_sum / total_person_pixels;

        float f_center_x = static_cast<float>(width) / 2.0f;
        float f_center_y = static_cast<float>(height) / 2.0f;

        // 2. Compute Centroid Offset (C_offset)
        float raw_offset = sqrt(pow(p_center_x - f_center_x, 2) + pow(p_center_y - f_center_y, 2));

        // 3. Compute Central Framing Ratio (R_frame)
        float raw_ratio = static_cast<float>(total_person_pixels) / static_cast<float>(size);

        // Apply temporal double exponential smoothing
        float smoothed_ratio = ratio_smoother_.Apply(raw_ratio);
        float smoothed_offset = offset_smoother_.Apply(raw_offset);

        // 4. Resolve Framing Classifications
        int framing_class = 1; // Standard Portrait
        if (smoothed_ratio < 0.15f) {
            framing_class = 0; // Wide Scenery (Neutral bypass zone)
        } else if (smoothed_ratio >= 0.50f && smoothed_offset < 50.0f) {
            framing_class = 2; // Extreme Center Focus (Suggestive close-up)
        }

        // Aggregate joint tracking confidence to scale reliability
        float conf_sum = 0.0f;
        int active_joints[4] = {11, 12, 23, 24};
        for (int idx : active_joints) {
            conf_sum += g_skeletal_coords_matrix[idx].confidence;
        }
        float aggregate_conf = conf_sum / 4.0f;

        FramingMetricsOutput output;
        output.central_framing_ratio = smoothed_ratio;
        output.centroid_offset_pixels = smoothed_offset;
        output.raw_subject_area = static_cast<float>(total_person_pixels);
        output.framing_classification = framing_class;
        output.confidence = aggregate_conf;

        return output;
    }

    void Reset() {
        ratio_smoother_.Reset();
        offset_smoother_.Reset();
    }

private:
    TemporalDoubleSmoother ratio_smoother_;
    TemporalDoubleSmoother offset_smoother_;
};

static CentralFramingSolver global_framing_solver;
static FramingMetricsOutput global_output_metrics;

extern "C" {
    __attribute__((import_name("onFramingMetricsResolved"))) void onConfidenceCalibrated(FramingMetricsOutput* output);

    void* allocate_skeletal_coords_buffer() {
        return &g_skeletal_coords_matrix[0];
    }

    void* allocate_person_mask_buffer(int size) {
        if (size > MAX_MASK_SIZE) return nullptr;
        return &g_person_mask_buffer[0];
    }

    void process_framing_evaluation(int width, int height) {
        FramingMetricsOutput results = global_framing_solver.Solve(
            &g_person_mask_buffer[0], 
            width, 
            height
        );
        global_output_metrics = results;
        onConfidenceCalibrated(&global_output_metrics);
    }

    void reset_framing_filters() {
        global_framing_solver.Reset();
    }
}
```

### 4.2 WebGPU Centroid Pixel Integrator Shader (`centroid_offset_integrator.wgsl`)
The following WGSL compute shader performs parallel pixel-level reduction and centroid calculation of the active person mask directly in GPU memory to compute the precise center of mass in real-time:

```wgsl
struct SystemConfig {
    width: u32,
    height: u32,
    patch_dimension: u32,
    padding: u32,
};

@group(0) @binding(0) var<uniform> config: SystemConfig;
@group(0) @binding(1) var<storage, read> person_mask: array<u32>; // W_frame * H_frame packed mask
@group(0) @binding(2) var<storage, read_write> output_centroid_map: array<vec2<f32>>;
@group(0) @binding(3) var<storage, read_write> active_pixel_counter: atomic<u32>;

@compute @workgroup_size(16, 16)
fn main(@builtin(global_invocation_id) global_id: vec3<u32>) {
    let x = global_id.x;
    let y = global_id.y;

    if (x >= config.width || y >= config.height) {
        return;
    }

    let index = y * config.width + x;
    let p_val = person_mask[index];

    // Compute pixel-level active coordinate values
    if (p_val == 1u) {
        let array_idx = atomicAdd(&active_pixel_counter, 1u);
        
        let patch_x = x % config.patch_dimension;
        let patch_y = y % config.patch_dimension;
        let output_index = patch_y * config.patch_dimension + patch_x;

        output_centroid_map[output_index] = vec2<f32>(f32(x), f32(y));
    }
}
```

### 4.3 TypeScript Orchestrator Wrapper (`CentralFramingEngine.ts`)
The TypeScript driver manages WebAssembly memory mappings, coordinates parallel WebGPU centroid pixel compute dispatches, and executes dynamic classifier modifications on device:

```typescript
export interface FramingMetricsResult {
  readonly centralFramingRatio: number;  // R_frame
  readonly centroidOffsetPixels: number; // C_offset
  readonly rawSubjectArea: number;
  readonly framingClassification: 'WIDE_SCENERY' | 'STANDARD_PORTRAIT' | 'EXTREME_CENTER_FOCUS';
  readonly confidence: number;
}

export class CentralFramingEngine {
  private wasmInstance!: any;
  private memory!: WebAssembly.Memory;
  private bufferOffsetCoords: number = 0;
  private bufferOffsetPersonMask: number = 0;
  private isLoaded: boolean = false;
  private device!: GPUDevice;
  private pipeline!: GPUComputePipeline;
  private patchDimension = 128;
  private maxMaskSize = 1024 * 1024; // Safe allocation bounds

  private latestResults: FramingMetricsResult | null = null;

  constructor() {}

  public async initialize(wasmArrayBuffer: ArrayBuffer): Promise<void> {
    const wasmImports = {
      env: {
        onFramingMetricsResolved: (metricsPtr: number) => {
          this.handleResolvedMetrics(metricsPtr);
        }
      }
    };

    const compiled = await WebAssembly.instantiate(wasmArrayBuffer, wasmImports);
    this.wasmInstance = compiled.instance.exports;
    this.memory = this.wasmInstance.memory;
    this.bufferOffsetCoords = this.wasmInstance.allocate_skeletal_coords_buffer();
    this.bufferOffsetPersonMask = this.wasmInstance.allocate_person_mask_buffer(this.maxMaskSize);

    if (this.bufferOffsetPersonMask === 0) {
      throw new Error("WASM Memory allocation failed for person mask arrays");
    }

    // Initialize WebGPU context
    const adapter = await navigator.gpu?.requestAdapter();
    this.device = await adapter?.requestDevice() as GPUDevice;

    const shaderModule = this.device.createShaderModule({
      code: `
        // WGSL code loaded from centroid_offset_integrator.wgsl
      `
    });

    this.pipeline = this.device.createComputePipeline({
      layout: 'auto',
      compute: {
        module: shaderModule,
        entryPoint: 'main'
      }
    });

    this.isLoaded = true;
  }

  public async evaluateFraming(
    personMask: Uint8Array,
    poseLandmarks: Float32Array, // 33 * 4 values
    width: number,
    height: number
  ): Promise<FramingMetricsResult | null> {
    if (!this.isLoaded || !this.device) return null;

    // Configure WebGPU buffers for high-speed parallel centroid pixel calculations
    const configBuffer = this.device.createBuffer({
      size: 16,
      usage: GPUBufferUsage.UNIFORM | GPUBufferUsage.COPY_DST
    });

    const pMaskBuffer = this.device.createBuffer({
      size: personMask.byteLength,
      usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_DST,
      mappedAtCreation: false
    });

    const outputCentroidBuffer = this.device.createBuffer({
      size: this.patchDimension * this.patchDimension * 8, // 128 * 128 * sizeof(vec2<f32>)
      usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_SRC
    });

    const atomicCounterBuffer = this.device.createBuffer({
      size: 4,
      usage: GPUBufferUsage.STORAGE | GPUBufferUsage.COPY_SRC | GPUBufferUsage.COPY_DST
    });

    // Write parameters to buffers
    const configData = new Uint32Array([width, height, this.patchDimension, 0]);
    this.device.queue.writeBuffer(configBuffer, 0, configData.buffer);
    this.device.queue.writeBuffer(pMaskBuffer, 0, personMask.buffer);

    const bindGroup = this.device.createBindGroup({
      layout: this.pipeline.getBindGroupLayout(0),
      entries: [
        { binding: 0, resource: { buffer: configBuffer } },
        { binding: 1, resource: { buffer: pMaskBuffer } },
        { binding: 2, resource: { buffer: outputCentroidBuffer } },
        { binding: 3, resource: { buffer: atomicCounterBuffer } }
      ]
    });

    const commandEncoder = this.device.createCommandEncoder();
    const passEncoder = commandEncoder.beginComputePass();
    passEncoder.setPipeline(this.pipeline);
    passEncoder.setBindGroup(0, bindGroup);
    passEncoder.dispatchWorkgroups(Math.ceil(width / 16), Math.ceil(height / 16));
    passEncoder.end();

    const stagingBuffer = this.device.createBuffer({
      size: this.patchDimension * this.patchDimension * 8,
      usage: GPUBufferUsage.COPY_DST | GPUBufferUsage.MAP_READ
    });

    commandEncoder.copyBufferToBuffer(outputCentroidBuffer, 0, stagingBuffer, 0, this.patchDimension * this.patchDimension * 8);
    this.device.queue.submit([commandEncoder.finish()]);

    await stagingBuffer.mapAsync(GPUMapMode.READ);
    stagingBuffer.unmap();

    // Map skeletal coordinate landmarks directly to the WASM heap
    const heapView = new Float32Array(this.memory.buffer, this.bufferOffsetCoords, 33 * 4);
    for (let i = 0; i < 33; ++i) {
      heapView[i * 4] = poseLandmarks[i * 4];         // X
      heapView[i * 4 + 1] = poseLandmarks[i * 4 + 1]; // Y
      heapView[i * 4 + 2] = poseLandmarks[i * 4 + 2]; // Z
      heapView[i * 4 + 3] = poseLandmarks[i * 4 + 3]; // Confidence
    }

    // Map person mask directly to the WASM heap
    const heapPersonMask = new Uint8Array(this.memory.buffer, this.bufferOffsetPersonMask, personMask.length);
    heapPersonMask.set(personMask);

    // Trigger WASM execution loop with parameters
    this.wasmInstance.process_framing_evaluation(width, height);

    return this.latestResults;
  }

  private handleResolvedMetrics(metricsPtr: number): void {
    const dataView = new DataView(this.memory.buffer, metricsPtr, 20); // sizeof(FramingMetricsOutput) = 20
    
    const centralFramingRatio = dataView.getFloat32(0, true);
    const centroidOffsetPixels = dataView.getFloat32(4, true);
    const rawSubjectArea = dataView.getFloat32(8, true);
    const framingClassificationInt = dataView.getInt32(12, true);
    const confidence = dataView.getFloat32(16, true);

    let framingClassification: 'WIDE_SCENERY' | 'STANDARD_PORTRAIT' | 'EXTREME_CENTER_FOCUS' = 'STANDARD_PORTRAIT';
    if (framingClassificationInt === 0) {
      framingClassification = 'WIDE_SCENERY';
    } else if (framingClassificationInt === 2) {
      framingClassification = 'EXTREME_CENTER_FOCUS';
    }

    this.latestResults = {
      centralFramingRatio,
      centroidOffsetPixels,
      rawSubjectArea,
      framingClassification,
      confidence
    };
  }
}
```

## 5. Comprehensive Edge Cases & Mitigations

### 5.1 Multiple Segment-Level Croppings
**Vulnerability:** A subject is framed extremely close-up so only specific body segments (e.g. chest or pelvic zones) are visible in the active viewport, causing standard full-body pose and aspect classifiers to fail due to missing head/limb coordinates.

**Mitigation Strategy:**
*   **Centroid Framing Evaluation:** The system calculates $R_{\text{frame}}$. If the subject area occupies $\ge 50\%$ of the active frame and skeletal joint tracking is highly incomplete (e.g., nose and ankle landmarks are missing with confidence $< 0.20$), the system identifies the scene as an extreme segment-level cropping.
*   **Action:** The decision engine immediately triggers an adaptive safety block, preventing highly suggestive cropped framing from bypassing standard rules.

### 5.2 Dynamic Foreground Interferences
**Vulnerability:** Fast-moving foreground elements (e.g., transition objects, text overlays, or other people) temporarily merge with the person mask, skewing the calculated center of mass ($C_{\text{offset}}$) and creating false-positive close-up zoom alerts.

**Mitigation Strategy:** The system executes double exponential temporal smoothing (`ratio_smoother_` and `offset_smoother_`) on-device. This dampens transient, high-frequency coordinate fluctuations, stabilizing the calculated framing ratios across frame sequences.

## 6. Physical & Environmental Influences

### 6.1 Camera Perspective Distortion Compensation
Foreshortening effects distort the boundary shape when the subject leans relative to the optical plane. To correct these distortions, the C++ normalizer maps the coordinates against the camera's intrinsic calibration parameters before running the Fourier transform calculations:

$$\begin{bmatrix} x_{\text{norm}} \\ y_{\text{normalized}} \end{bmatrix} = \begin{bmatrix} 1.0 & 0.0 \\ 0.0 & \cos(\theta_{\text{pitch}}) \end{bmatrix} \begin{bmatrix} x_{\text{raw}} \\ y_{\text{raw}} \end{bmatrix}$$

The calculated central framing ratio (`centralFramingRatio` or $R_{\text{frame}}$) modifies the active safety thresholds across adjacent modules:

```text
Pose_Verification_Interval_Frames = Max(1, Math.floor(15 * (1.0 - R_frame)))
Skin_Exposure_Tolerance_Ratio = Skin_Baseline * (1.0 - R_frame * 0.45)
```

If $R_{\text{frame}} \ge 0.50$ (Extreme Center Focus) with low $C_{\text{offset}}$ in a non-athletic, non-educational setting, the system increases its evaluation rate to every single frame and lowers the acceptable exposed skin thresholds, ensuring that any suggestive contour styling is blocked with maximum precision.
